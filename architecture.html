Geospatial data engineering

Morocco Climate & Water Observatory

An observatory that brings rainfall, temperature, soil moisture, and mapped infrastructure into one view so users can compare climate and water indicators across Morocco.

  1. CHIRPS, ERA5-Land, and OpenStreetMap
  2. MinIO and Spark/Delta
  3. Silver validation and dbt Gold models
  4. Power BI and Streamlit

How it works

Airflow orchestrates a medallion pipeline. Source files land in MinIO. Spark and Delta prepare regional observations, and Silver checks validate types, ranges, nulls, and duplicates before publication. dbt builds the Gold models used by the dashboards. A shared layer keeps measures such as seasonal departures and water-year rainfall totals consistent across both interfaces.

Scale and data quality

The repository documents 120 monthly time steps across 2015–2024 and 3.25 million retained rainfall grid records. Sampling, area weighting, and the distinction between global downloads and Morocco-specific outputs matter when interpreting those figures. Invalid records are quarantined at the publication gate.

Computer vision & MLOps

Vision Studio

A platform for running vision workflows across different camera types and ML models from a common interface.

  1. USB, IP, or industrial camera
  2. Camera and model adapters
  3. Inference and project rules
  4. Live monitoring or review

Design decision

Camera and model interfaces keep project logic independent of hardware and framework implementations. A project can use a USB or RTSP input and switch between detection and segmentation through adapters. A Flask API and React interface expose project configuration and live monitoring, including rules and regions of interest.

Deployment and review

The repository provides Docker Compose for an edge setup and infrastructure definitions for Azure using Terraform, Kubernetes, and Helm. It also documents a workflow for collecting low-confidence frames for human review and possible retraining.

Signal processing

Stress Peak Detection from EEG

A collaborative project that uses signal processing and a CNN–LSTM to study stress classification from EEG recordings.

  1. Multichannel EEG
  2. Bandpass and notch filters
  3. Artifact removal and downsampling
  4. Time and frequency features

From waveform to model input

The preprocessing module reduces out-of-band noise and power-line interference, uses optional independent component analysis (ICA) for artifact removal, and downsamples the signal. It can extract and normalize time- and frequency-domain features over overlapping windows. The project combines convolutional layers for local patterns with an LSTM for temporal dependencies.

Collaboration

The EEG preprocessing module credits Youssef Mahdi and Hamza El Haiki as authors.

Agentic AI

Agents for Agriculture

A retrieval-augmented generation system for questions about irrigation, crop management, and water use.

  1. Technical documents
  2. Semantic chunks and indexes
  3. Hybrid retrieval and knowledge graph
  4. Specialist agents and cited answers

Retrieval and orchestration

The system ingests technical PDFs, indexes semantically grouped text, and combines embedding-based and keyword search. A knowledge graph adds a route for questions about relationships between domain concepts. Reranking helps select evidence for the answer, and citations connect responses back to the retrieved sources.

Specialist agents

The API exposes agents for tasks such as irrigation planning and climate risk. The project adds weather context and persistent user-controlled memory for farm inputs across consultations. The repository includes evaluation modules and AWS deployment configuration.

Explainable machine learning

Explainable IoT Intrusion Detection

A collaborative Kaggle project that classifies benign and malicious network traffic and examines which features drive those predictions.

  1. CIC IIoT 2025 traffic windows
  2. Feature engineering and selection
  3. CNN–BiLSTM–Transformer
  4. Evaluation and SHAP explanations

Model and evaluation

The PyTorch notebook implements a hybrid classifier and a lighter variant. The full model combines convolutional branches, bidirectional LSTM layers, and attention. Evaluation code calculates classification metrics and times single-sample inference. The SHAP section uses KernelExplainer to inspect global feature importance, class-level contributions, and individual predictions.

Cloud data engineering

Finance ETL on Google Cloud

An invoice-to-cash and support analytics project for a fictional B2B SaaS company, covering overdue invoices, payment risk, and support costs.

  1. Invoices and support events
  2. Validation and quarantine
  3. Warehouse models and marts
  4. Finance and support analytics

Reliable loads and business metrics

The local implementation generates synthetic records, handles duplicates and invalid rows, and loads models for accounts receivable aging, days sales outstanding, invoice risk, and support costs. Business keys make reruns repeatable. A configurable report date makes historical runs reproducible.

Cloud deployment design

The GCP architecture describes separate batch and event-streaming paths using Cloud Storage, Pub/Sub, Dataflow, Cloud Composer, BigQuery, and dbt. The runnable local path provides a way to inspect data quality behavior and analytical outputs before deploying cloud infrastructure.
